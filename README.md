# Spam Mail Detector

## Overview

This project uses Machine Learning and Natural Language Processing (NLP) techniques to classify messages as Spam or Ham (Not Spam).

## Features

* Text preprocessing
* Stopword removal
* TF-IDF feature extraction
* Naive Bayes classification
* Spam prediction on new messages

## Dataset

SMS Spam Collection Dataset

## Technologies Used

* Python
* Pandas
* NLTK
* Scikit-Learn
* TF-IDF Vectorizer
* Naive Bayes

## Workflow

1. Load Dataset
2. Text Preprocessing
3. Feature Extraction using TF-IDF
4. Train-Test Split
5. Model Training
6. Performance Evaluation
7. Spam Prediction
